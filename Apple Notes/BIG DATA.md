<p style="text-align:left;margin:0">#topicos_avancados 

<b><i>Azure Data Factory</i></b>, é possível utilizar Azure Data Factory ou Apache Oozie e Sqoop como tecnologia de orquestração para automatizar fluxos de trabalho.

Em <b>Big Data</b>, o processamento de fluxo é uma técnica de processamento de dados em tempo real, que permite capturar, processar e analisar dados à medida que são gerados, possibilitando tomadas de decisões mais rápidas e eficientes. Como exemplo de ferramenta, podemos citar o Azure Stream Analytics, que oferece um serviço de processamento de fluxo gerenciado baseado em consultas SQL em execução perpétua que operam em fluxos não associados.


A fonte de dados é o ponto de partida para qualquer solução de Big Data, e pode incluir uma variedade de fontes. Alguns exemplos de fontes são: Armazenamentos de dados de aplicativo, como bancos de dados relacionais; Arquivos estáticos produzidos por aplicativos, como arquivos de log do servidor Web; e Fontes de dados em tempo real, como dispositivos IoT.


O processamento em lotes (em batch) é uma técnica que processa grandes volumes de dados em lotes, geralmente durante um período de tempo programado. ele é usado para filtrar, agregar e preparar dados para análise em conjuntos de dados muito grandes.


O armazenamento de dados é uma das principais funções do Big Data, e geralmente faz uso de um repositório de arquivos distribuído que pode conter vários volumes de arquivos grandes em diferentes formatos. Esse repositório (geralmente chamado de Data Lake) é usado para armazenar dados de operações de processamento em lotes, bem como outros tipos de dados, para análise posterior.


<b>DATAFICATION</b> O termo tem origem na língua inglesa, com a palavra "Datafication" e, de acordo com Mayer Schonberger and Cukier, autores da obra Big Data, diz respeito à transformação de diversos aspectos do mundo concreto e físico em em dados quantificados on-line, permitindo o rastreamento em tempo real, além da aplicação de ferramentas de Analytics (Descritivo, Diagnóstico, Preditivo e Prescritivo).
</p>

<p style="text-align:justify;margin:0">Esse fenômeno trata-se de coletar informações anteriormente invisíveis digitalmente e transformá-las em dados. Estas informações podem ter como fonte os seres-humanos, animais e a natureza ou, até mesmo, máquinas, objetos, processos e atividades em geral. Após essa conversão, as empresas passam a poder rastreá-los, monitorá-los e otimizá-los, de forma a oferecer novas formas de valor para negócios e para a sociedade


</p>
