Resposta a entrevista assíncrona do IMPULSE

Para fazer testes já utilizei o Mini Test, que é o padrão do Rails, e mais amplamente o RSpec que é o mais utilizado no mercado. Na maioria das vezes depois do desenvolvimento de uma funcionalidade ou de uma ação importante dentro do código o teste de unidade validou o que foi escrito naquele trecho desenvolvido, no entanto, o teste de integração serviu para validar se o código inserido não causaria problemas no fluxo no qual ele foi inserido.
