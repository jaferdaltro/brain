### 1 - What is constructor in OOP? 
In object-oriented programming (OOP), a constructor is a special method or function that is automatically called when an object is created. Its primary purpose is to initialize the object's attributes or properties and perform any setup required for the object to function correctly. Constructors are commonly used to ensure that an object starts in a valid state.
