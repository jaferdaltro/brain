Trabalhava em uma API para o gerenciamento de restaurantes e o sistema já gerava um padrão dos dados
Meu gerente me pediu para integrar nosso sistema a uma API que estava completamente diferente e eu iria atuar sozinho, pois trabalhava em uma startup e não havia outros 
Desenvolvedores backend, o desafio era fazer essa integração sem muito contexto pois eu não conhecia completamente o sistema pois estava a apenas 2 meses na companhia.

Utilizando o Postman tive que ajustar nossos dados para retornar o padrão esperado, foram feitos alguns parceamentos para que tudo ficasse perfeito.

Após todo o trabalho consegui alcançar o objetivo esperado.
