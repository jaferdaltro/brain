- A área visível do navegador é chamada de view-port
	- width: 10vw é 10% da largura do viewport

- Padrão 16px de fonte
- Se eu configurar o meu font-size do meu html para 62,5%, posso utilizar medidas relativas com maior facilidade, por exemplo:
	- Se quiser que minha largura seja de 300px, posso colocar a largura relativa com 30rem

### Unidades de medida
- em 
	- Se baseia no elemento mais próximo 
- rem
	- Se baseia no elemento root do documento
