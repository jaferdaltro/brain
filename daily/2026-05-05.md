**Steps to Reproduce:**  
1. Install the latest STG build 56.42616.2200.0.  
2. Open the HPSA URL [https://support.hp.com/us-en](https://support.hp.com/us-en "Follow link") and sign in with the old account [qiaocatherine8@gmail.com/admin!!12345![](https://hp-jira.external.hp.com/images/icons/mail_small.gif)](mailto:qiaocatherine8@gmail.com/admin!!12345 "Follow link"). (Provided in test case [T2058173891](https://hp-testrail.external.hp.com/index.php?/tests/view/2058173891 "Follow link"))  
3. Navigate to HPSA dashboard page and check all the added devices. (Shows total 24 devices under My Devices)  
4. Launch the HPX and sign in with the same account in step2.  
5. Navigate to HPX device list page and check all the devices (Total 12 devices).  
6. Compare the device list info with the HPSA dashboard devices info.

**Expected Result:**  
All the devices shows in HPSA dashboard/My Devices should be synced and showed in HPX device list. 

**Actual Result:**  
Some devices (like **SN: 5CG0468Z52, SN: CND8301HV2**,) added previously cannot be synced and showed in HPX device list.
